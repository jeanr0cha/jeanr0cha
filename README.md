## Graduando em Engenharia de Computação | Estagiário de Sistemas e Desenvolvimento
Estudante de Engenharia de Computação, e atualmente estou como estagiário de sistemas e desenvolvimento no Detran-ES, algumas das minhas atividades são:

  * Extração e tratamento de dados de bancos de dados utilizando Python e ETL (SSIS).
  * Desenvolvimento de dashboards para visualização de dados e criação de métricas na linguagem DAX.
  * Automação de processos com Python, n8n e o orquestrador de dados Kestra.
  * Suporte Técnico N1: Atendimento a chamados de usuários via sistema GLPI ou Teams, criando usuários no Sistema OnBasse e resolvendo demandas relacionado ao mesmo.
